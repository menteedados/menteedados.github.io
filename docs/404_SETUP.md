# 📄 Página 404 Personalizada - Documentação

## O que é?
Página exibida quando um usuário tenta acessar uma URL que não existe no site.

## Arquivos criados

| Arquivo | Descrição |
|---------|-----------|
| `/404.html` | Página 404 personalizada (na raiz do projeto) |
| `/test-404.html` | Página auxiliar para testar links 404 |

## Funcionalidades

### 1. Design consistente
- Cores da marca (navy, gold)
- Tipografia Playfair Display + Source Serif
- Efeito de fundo com gradiente

### 2. Mensagem amigável
- "404 - Dado não encontrado"
- Referência ao universo de dados
- Tom leve e acolhedor

### 3. Links úteis
- ← Voltar para a página inicial
- Home
- Trilha 00
- Contato

### 4. Botão principal
- "Ir para a página inicial →"
- Link direto para home

## Como funciona no GitHub Pages

O GitHub Pages automaticamente serve o arquivo `404.html` na raiz quando uma página não é encontrada.

**Não precisa de configuração adicional!**

## Como testar

1. Depois de publicado, acesse: `https://menteedados.github.io/pagina-que-nao-existe`
2. A página 404 personalizada deve aparecer
3. Teste os links de navegação
