## 🚀 Deploy

O site é hospedado no GitHub Pages: https://menteedados.github.io

## 🌿 Git Flow

- `main`: produção (deploy automático)
- `dev`: desenvolvimento ativo

## 📝 Como contribuir

1. Trabalhe sempre na branch `dev`
2. Crie features branches: `feature/nome-da-feature`
3. Faça PR para `dev`
4. Após testes, merge `dev` → `main`

- GitHub Pages
